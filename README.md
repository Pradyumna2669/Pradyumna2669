- 🚀 **Flagship Build**: Creator of [**PaperGen.online**](https://papergen.online) — an AI-powered question paper generator built for Indian teachers with 17+ regional languages and 8-second handwriting scan-to-digitize OCR.
- 🏛️ **Campus Software Architect**: Engineered **QuizArena** (real-time multiplayer live quiz & Codethon judge), **Hallify** (Seminar Hall booking portal), and the **PR Pote Appointment & Visitor Desktop Portal**.
- 🤖 **Automation Specialist**: Built Discord study compliance bots enforcing webcam/screen-share protocols with dual Firebase & SQLite persistence.
- 🏅 **Hardware & Embedded**: Built the **SAR (Service Automated Robot)** with state-level distinction at Vigyan Bharati (VIBHA), and developed an automated IoT **Smart School Bell System**.
- 💬 **Ask me about**: Next.js 15, React 19, Supabase, WebSockets, Discord.js, Electron desktop apps, and system design.
